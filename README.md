## 📌 About

This repository is my personal, ongoing record of learning Data Structures and Algorithms — one topic at a time, in C++. Each file represents a concept I've actually sat down, understood, and implemented from scratch, rather than a dump of unrelated snippets.

The goal is twofold: build a reliable personal reference I can revisit later, and put something genuinely useful out there for anyone else working through the same fundamentals.

---

## 🗂️ Repository Structure

```text
Data-Structures-and-Algorithms/
│
├── 001_LinearSearchForward.cpp
├── ...
└── README.md
```

Every topic lives as a single, self-contained `.cpp` file directly in the repo root — no nested folders, no scattered scratch work. Just clean, numbered, one-concept-per-file implementations.

---

## 🏷️ Naming Convention

```text
<number>_<TopicName>.cpp
```

**Example:** `001_LinearSearchForward.cpp` → the 1st topic added, Linear Search (forward direction).

The number reflects the order I learned and added each topic — not a difficulty ranking. New files are added as new topics are learned, so the numbering grows over time.

## ⚙️ How to Compile & Run

Each file is fully self-contained and can be compiled independently.

```bash
g++ -std=c++17 -O2 -o output 001_LinearSearchForward.cpp
./output
```

**Windows**
```bash
output.exe
```
